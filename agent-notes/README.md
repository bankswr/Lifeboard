# agent-notes

Shared scratch-and-reference space for AI agents working on this project.
Agents should **read** this folder before starting work and **write** here to leave
context for future agents (and humans).

## What belongs here
- Decisions and their rationale (why something was done a certain way)
- Findings from investigations, research, or debugging sessions
- Handoff notes: work in progress, next steps, open questions
- Gotchas, conventions, and references that aren't obvious from the code

## What does not belong here
- Secrets, credentials, or personal data
- Content that duplicates the code, git history, or CLAUDE.md
- Large generated artifacts or build output

## Conventions
- One topic per Markdown file, named `YYYY-MM-DD-short-topic.md` (e.g. `2026-09-16-auth-approach.md`).
- Start each file with a short summary line, the date, and the author (agent/human).
- Update an existing note rather than creating a duplicate; mark stale notes as **Superseded** with a link to the replacement.
- Keep `INDEX.md` current: add one line per note.
